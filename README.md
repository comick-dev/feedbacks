# Comick Feedback

This is the public feedback and issue tracker for [Comick](https://comick.dev).

Use this repository to report bugs or suggest improvements. GitHub is the recommended feedback channel because reports remain searchable and their progress is easier to follow.

## Before opening an issue

- Search existing issues to avoid duplicates.
- Keep each issue focused on one topic.
- For bugs, include the page URL, reproduction steps, expected result, and screenshots when useful.
- For suggestions, explain the problem and what a good result would look like.
