# Contributing to Comick Feedback

Thanks for helping improve Comick!

This repository is used for reporting bugs and suggesting improvements to Comick. Before contributing, please follow these guidelines.

## Before opening an issue

* Search both open and closed issues to avoid duplicates.
* Check the [Roadmap](https://app.notion.com/p/meotimdihia/c76b651424df4d46837e4710301340bd?v=c152efba2ae84bb6b0c2a615539d83e2) to see whether the suggestion is already planned.
* Keep each issue focused on one topic.
* Choose the appropriate issue template.

## Advice on Searching to Avoid Duplicate Issues

GitHub provides several ways to search and filter existing issues. Some commonly useful labels include:

* **Add Scraping**
* **Admin Tool**
* **Custom List**
* **Search/Filter**
* **UI**

These are only some of the available labels, and not every issue will use one of them. You can also search using other filters, such as **Assignee**, **State**, and more.

To search for issues with a specific label:

1. Click the issue search/filter bar.<img width="1080" height="936" alt="image" src="https://github.com/user-attachments/assets/1c3dd1d1-3ac6-4fb7-94db-cb082e357385" />

2. Press **Space**.

3. You will see several filter options. Select **Label**, then choose the label you want to search for.

4. You can use multiple labels at the same time. To add another label, type **Label** again and select the next one.

5. You can also filter issues using other options, such as **Assignee**, **State**, and more.

Please search existing issues before creating a new one. This helps prevent duplicate requests and keeps the issue tracker organized.

## Bug reports

* Include the affected page URL.
* Describe the steps needed to reproduce the problem.
* Explain what you expected to happen and what happened instead.
* Add screenshots or other useful details when relevant.

## Suggestions

* Clearly explain the problem you are trying to solve.
* Explain the proposed solution or desired result.
* Include examples or screenshots when they help clarify the idea.

## Community guidelines

* Be respectful and constructive.
* Keep discussions civil and on-topic.
* Do not harass, insult, spam, or create bad-faith issues.
* Respect maintainer decisions and feedback.

## General guidelines

* Use Discord for general questions or discussion.
* Avoid creating duplicate issues just to draw attention to an existing request. Add a comment or reaction instead.
* Issues may be closed, merged, or redirected when appropriate.

### Thank you!

Thanks for taking the time to read these guidelines and help make Comick better. Your feedback and suggestions are appreciated!
